# CHOCOLATE-SALES-DATA
# Chocolate Sales Data Analysis 🍫📊

## Overview
This project analyzes chocolate sales data to understand sales performance, profit, returns, and inventory trends using Power BI.

## Data
The dataset includes cleaned CSV files for:
- Customers
- Products
- Sales Transactions
- Inventory Snapshot
- Returns
- Warehouses

## Tools Used
- Power BI
- SQL
- Excel
- Git & GitHub

## Key Analysis
- Total Sales & Profit
- Product-wise performance
- Region & warehouse analysis
- Returns and inventory insights
